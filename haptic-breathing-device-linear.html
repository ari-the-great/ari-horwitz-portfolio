Linear Tapping Haptic Guided Breathing Device

Similar to the radially expanding wearable, this device is another modality for guided breathing. Instead of cam followers that drag on the skin, this design involves 6 servo motors that tap sequentially.

Circuit Design

Using tools such as TinkerCAD, I was able to test and improve the code on a working virtual circuit in forgiving environment.

Coding

Starting from strach, I designed the code to be modular and customizable. The code allows the servos to tap for a specified cycle time, at a specified speed, for a specified number of cycles. The code uses the millis() function to track the time while allowing other commands to be performed.

Soldering and Prototyping

To test the device on users, I constructed a fully functioning prototype of the wearable. I soldered wires and components to best fit the servos on the wearable without restricting motion of the user.
